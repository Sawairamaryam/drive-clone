# Drive Clone

A PHP-based file management web application inspired by cloud storage platforms.

## Features

- User signup, login & logout
- Authentication & session management
- File upload, download & preview
- Multiple file uploads
- Folder creation & organization
- Rename, move & copy files
- Delete & permanent delete
- Trash functionality
- File sharing & public sharing
- Recent & starred files
- Storage management

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- GitHub

## Local Setup

1. Install XAMPP.
2. Place the project inside `htdocs`.
3. Start Apache and MySQL.
4. Create the required MySQL database.
5. Configure the local database connection.
6. Open the project through `localhost`.
