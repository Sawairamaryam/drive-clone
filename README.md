# Drive Clone

A PHP-based file management web application inspired by cloud storage platforms.

## Overview

Drive Clone is a web application that allows users to manage their files through a simple web interface. The project includes user authentication, file and folder management, sharing features, and file organization.

## Features

- User signup and login
- User logout
- Authentication and session management
- File uploads
- Multiple file uploads
- Folder creation
- File and folder organization
- File download
- File preview
- Rename files
- Move files
- Copy files
- Delete and permanently delete files
- Trash functionality
- File sharing
- Public file sharing
- Recent files
- Starred files
- Storage management

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- GitHub

## Project Structure

The project contains separate PHP files and folders for authentication, dashboard functionality, file management, uploads, and other application features.

## Local Setup

1. Install XAMPP.
2. Place the project inside the `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Create the required MySQL database.
5. Configure the database connection locally.
6. Open the project through `localhost` in a web browser.

## Important Note

This repository is provided as a portfolio/project demonstration.

Database credentials, uploaded user files, and other private or environment-specific data should not be committed to the repository.

## Development

This project was developed as a practical PHP web application to explore authentication, database integration, file management, and CRUD functionality.
